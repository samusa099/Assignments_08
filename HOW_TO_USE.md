# 📘 How, Where & Why to Use This Project

## Project
**E-School — Responsive Education Landing Page**

## Why Use It

This repository is useful for learning how to structure an education-focused landing page with Bootstrap navigation, feature statistics, course cards, seat and date information, testimonials, calls to action, and a responsive grid.

Use it to:

- Practise Bootstrap layout and components
- Study education and course-card interfaces
- Learn responsive section composition
- Build portfolio evidence for front-end skills
- Experiment with course catalogue presentation

## Where It Can Be Used

- Learning-platform prototypes
- Classroom or bootcamp assignments
- Front-end portfolios
- Course marketplace UI practice
- Education campaign landing pages

> The course, sign-in, and purchase controls are static. Connect them to real services before production use.

## How to Use It

```bash
git clone https://github.com/samusa099/Assignments_08.git
cd Assignments_08
```

Open `index.html` in a browser or use **VS Code Live Server**.

### Customisation Steps

1. Edit navigation, hero, features, courses, testimonials, and footer in `index.html`.
2. Replace logos, course images, and icons inside `images/`.
3. Adjust branding and layout in `css/style.css`.
4. Update course names, dates, seat numbers, and calls to action.
5. Test cards and navbar across mobile, tablet, and desktop widths.

## File Guide

| File or Folder | Purpose |
|---|---|
| `index.html` | Complete education landing-page structure |
| `css/style.css` | Custom project styling |
| `images/` | Logo, hero, feature, course, and testimonial assets |
| `README.md` | Project overview and quick start |
| `HOW_TO_USE.md` | Detailed usage, customisation, and reuse guide |

## Recommended Workflow

1. Review the full page in a browser.
2. Replace content and images with a consistent course theme.
3. Confirm Bootstrap classes before adding custom CSS.
4. Test card alignment at each breakpoint.
5. Add real routes or application logic only after the UI is stable.
6. Validate accessibility and image alt text.

## Suitable Practice Tasks

- Add course filtering
- Create a course-details page
- Connect sign-in and purchase actions
- Improve card accessibility
- Add a working testimonial carousel
- Deploy the project with GitHub Pages

## Limitations

- Static front-end demonstration
- No authentication, enrolment, or payment system
- Course data is hard-coded
- Content and image licences require review before commercial use
